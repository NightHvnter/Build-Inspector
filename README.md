# Build-Inspector
Build Inspector è un programma che aiuta l'utente a stabilire se il suo computer è in grado a correre un gioco

## Installation

Andare sul sito di [Build Inspector]() e scaricare l'ultima versione premendo il tasto in alto a destra.

---
Recarsi sulla pagina delle [Release](https://github.com/NightHvnter/Program-Inspector/releases) di GitHub e scaricare la versione che si preferisce.
